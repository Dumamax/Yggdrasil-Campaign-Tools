⟡ Yggdrasil Guild Hall

The DM's prep and table tools.

Keep the hooks you like; mark them Final to send their Quest Notices to Print and to the At the Table view. "Paid → treasury" adds the guild fee.

Skill grades: Proficient = Skilled; Expertise = Expert; Expertise at level 11+ = Master. "Proficient (auto)" / "Expertise (auto)" follow a PC's level. Retiring a PC keeps them in the hall as an NPC who can operate a facility.

Campaign file

The campaign file is the source of truth: jobs, upgrades, treasury, roster, write-ups, and any custom tables. The page also keeps a working copy in this browser, but save a file after each prep session and keep the files somewhere safe (Drive, Dropbox, USB).

Import pasted data

Paste an export from the old Job Board or Upgrade Chart (or a campaign file's contents).

Claude

The key stays in this browser only; it's never written into the campaign file or this page. Use a dedicated key with a monthly spend limit set in the Claude Console.

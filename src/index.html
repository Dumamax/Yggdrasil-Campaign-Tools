Printing

Campaign file

The campaign file is the source of truth: jobs, upgrades, treasury, roster, write-ups, and any custom tables. The page also keeps a working copy in this browser, but save a file after each prep session and keep the files somewhere safe (Drive, Dropbox, USB).

Backups in this browser

Taken automatically when you save, before loading a file or restoring, and every 5 minutes while you have unsaved changes (last 25 kept). They live in this browser only, so they're a safety net, not a replacement for the campaign file.

Import pasted data

Paste an export from the old Job Board or Upgrade Chart (or a campaign file's contents).

DM password

Keeps players from wandering into DM Mode. It travels with the campaign, so after a change, save so other copies pick it up. This isn't strong security: the campaign file itself isn't encrypted.
